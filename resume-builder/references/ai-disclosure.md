# Saying where AI was used

Why: employers, schools and coordinators increasingly ask. Hiding AI risks trust; overstating it ("AI did it all") risks the person's credibility. The honest middle is to show AI inside specific steps and what the person did.

## Rules
- Name only tools the person confirmed in Round 7 (Q46). Never add a tool because it is popular.
- Describe a step, not a magic result: "Used <tool> to draft <what>, then edited and tested it myself."
- State what the person did: decided the question, supplied the data or assumptions, edited, tested, checked the numbers.
- Do not write an AI claim the person cannot explain in an interview. If they answered "no" to Q47, word it carefully and add a practice note in `needs-input.md`.
- If a posting or school says to limit or disclose AI use, follow it.
- Put it where it fits: one clause in the summary, the tools in the Skills line ("AI tools (X) to draft code and checks"), and the step in each relevant project bullet.

## Patterns
- "Used Claude to draft summaries from lecture slides, then edited, added examples and checked every answer myself."
- "Drafted the SQL with an AI assistant; I chose the question, tested each query against the raw data and rewrote two that gave wrong totals."
- "Built a prototype with AI help, then ran the test script and fixed the failures."

## What not to write
- "Leveraged cutting-edge AI" (empty and a banned word).
- "Expert in AI" without a project that shows it.
- Any step the person did not describe.

## Interview line
Help the person prepare one honest sentence for each AI-assisted project: "AI drafted X. I decided Y, edited Z and tested it by doing W. I can walk through it."

## Where it belongs
State AI use where it affects the person's work (a project, a research task), not on a resume merely because Claude helped write the resume. At handover, tell the person plainly that Claude drafted the documents from their answers and that they are responsible for every line.
