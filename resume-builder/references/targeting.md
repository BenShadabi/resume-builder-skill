# Choosing targets and lanes

A **lane** is a group of similar job titles that can share one resume. Most people need 1 to 3 lanes. More than three means the resume tries to be everything and convinces nobody.

## Step 1: Turn answers into lanes
From Round 2, write each lane as: titles, industries, what the resume must prove. Example:
- Lane A: data analyst, business analyst. Must prove: SQL or Excel, a real analysis with a result.
- Lane B: operations or customer-facing roles. Must prove: handling people, process improvement with numbers.

Rank the lanes. Ask the person which one they would be happiest to get, not which is easiest.

## Step 2: Honest fit score (0 to 100)
For each posting give a rough score and one line of reason. Look at:
- Eligibility lines first (work authorization, graduation window, degree level, location, term dates, language). A mismatch here beats any skill match; tell the person plainly.
- Must-have skills they truly have versus gaps.
- Level: is it an internship, entry or senior role?
If the score is under about 40, say so and ask before building. Borderline roles (40 to 60) are still worth a package when the person wants them, because fit on paper is not the same as fit in a room.

## Step 3: Check the posting is alive
Open the page. Skip if it says closed, "no longer accepting applications", or the term or start date is wrong. Note the deadline if there is one. Many postings die in days, so apply early.

## Step 4: Pick what to tailor
Per posting, decide: which summary phrase, which skills first, which bullets lead, which 1 to 2 projects. Everything else stays identical to the master so the person can defend every line.

## Employer-specific rules
Portals sometimes demand one combined PDF, a transcript, a certain length or a certain file name. Read the posting's application instructions and follow them; the portal's rules win over this skill.

## If the person gives posting text instead of a link
Save the text to `posting.txt` and say plainly that you could not check if it is still open. Ask them to check the page themselves and note the date they checked.
